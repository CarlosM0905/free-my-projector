Install

Ten minutes, one computer.

You need a computer on the same Wi-Fi as the projector, with adb, and network debugging on in the projector (Wanbo projectors ship with it open on port 3333).

Install

Connect to the projector and install. Use your projector's address.

adb connect 192.168.1.50:3333
adb install -r FreeMyTV.apk

Switch

On the projector, open Free My Projector → Home Screen → Free My Projector, wait a minute and press Home. Add your city and a free TMDB key in Preferences.

FAQ

Good questions.

Which projectors does it work on?

Android 9 or newer, with network debugging. It's built and tested on a Wanbo T6 Max (Amlogic T972); the keystone, focus, lamp and fan controls use that hardware, and simply don't appear where they can't work. The home screen, Control Center, lyrics and screensaver work on any Android TV device.

Do I need root?

No. It uses the projector's own network debugging, the same way you installed it, to switch the home screen and reach a few settings.

How do I go back to the original home screen?

Open Free My Projector → Home Screen → Original. Your previous home screen, screensaver and apps come back as they were. If the new home screen ever crashes three times in five minutes, it goes back by itself.

Why does it ask for a TMDB key?

The recommendations, artwork and title pages come from The Movie Database. A personal key is free and takes two minutes; without it you still get the home screen, a large clock and everything else.

Does it collect anything?

No account and no analytics. It talks to TMDB, Open-Meteo (weather and air), Wikimedia Commons (backgrounds), lrclib (lyrics) and GitHub (updates), and that's it.

How does it update?

Once a day it checks this project's latest release on GitHub and installs it only if it's newer and signed with the same key. After updating, a sheet shows what's new.
